# Analiza danych

Analiza jest zapisana w `backend/app/ml/eda.py`, żeby można było uruchomić ją ponownie bez ręcznego wykonywania komórek. Uruchomienie `python -m scripts.train` w katalogu backend tworzy `eda.png` i `eda.json` w katalogu wersji modelu.

W tym katalogu można później dodać własny notebook z opisem i interpretacją wykresów. Nie kopiujemy notebooków konkursowych. EDA wykonujemy na części treningowej, z tym samym podziałem co skrypt treningowy.
